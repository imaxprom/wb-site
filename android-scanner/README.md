# Сканер отгрузки

Нативное Android-приложение для Zebra MC2700 (Android 10+) и DataWedge 8.2.

## Рабочий процесс

1. Выбрать маркетплейс и направление.
2. Отсканировать цифровой баркод товара.
3. Ввести количество на клавиатуре ТСД — отдельное подтверждение не требуется.
4. Отсканировать буквенно-цифровой ШК короба.
5. Повторить; одинаковый ШК короба считается одним уникальным коробом.
6. Завершить, проверить итог и отправить `.xlsx` через почтовое приложение.

Четвёртый столбец `Срок годности` присутствует в каждом файле и остаётся пустым.

## DataWedge

При первом запуске приложение создаёт профиль `ShipmentScanner`, привязанный только к пакету
`ru.imaxprom.shipmentscanner`. Профиль использует аппаратный сканер, Intent Output и отключает
Keystroke Output только внутри этого приложения. Существующий профиль Excel не изменяется.

## Сборка

```sh
export JAVA_HOME=/opt/homebrew/opt/openjdk@17/libexec/openjdk.jdk/Contents/Home
export ANDROID_HOME=/opt/homebrew/share/android-commandlinetools
./gradlew test assembleDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`.

## Важное ограничение Android

Android не сообщает приложению, действительно ли Gmail отправил письмо. Поэтому после возврата
из почты приложение спрашивает `Письмо отправлено?`. Только ответ `Да` закрывает текущую отгрузку.
При ответе `Нет` все данные и файл остаются доступны для повторной отправки.
